🚀 _**Weekly Coding Projects**_ 🌑

Un proyecto semanal para aprender, experimentar y seguir creciendo como desarrollador.

👋 **Sobre este proyecto**

Me encanta aprender cosas nuevas, especialmente cuando puedo hacerlo construyendo proyectos reales.

Este repositorio nace con una idea sencilla: crear un proyecto de programación cada semana para seguir practicando, descubrir nuevas tecnologías y enfrentarme a problemas diferentes.

Considero que una de mis fortalezas es mi capacidad para aprender rápidamente. Cuando encuentro una tecnología, herramienta o concepto que no conozco, intento entenderlo, ponerlo en práctica y convertir ese conocimiento en algo funcional.


🎯 Objetivo 🎯

El objetivo principal de este proyecto no es crear aplicaciones perfectas, sino aprender constantemente mediante la práctica.

Cada semana intentaré:

🧠 Aprender algo nuevo.

💻 Construir un proyecto desde cero.

🔍 Investigar tecnologías, herramientas o conceptos diferentes.

🧩 Resolver problemas y enfrentarme a nuevos retos.

📈 Mejorar mis habilidades de programación.

📝 Documentar lo aprendido.

🚀 Experimentar y salir de mi zona de confort.

📅 Un proyecto cada semana

Cada proyecto representa una semana de aprendizaje.

Los proyectos pueden ser muy diferentes entre sí: desde pequeñas herramientas y automatizaciones hasta aplicaciones completas, experimentos con nuevas tecnologías o ideas que simplemente quiera explorar.

No existe una temática fija. La única regla es seguir aprendiendo.

Semana 01 → Proyecto_1
Semana 02 → Proyecto_2
Semana 03 → Proyecto_3
...
Semana N  → Proyecto_N

🛠️ Tecnologías 🛠️

La tecnología utilizada dependerá de lo que quiera aprender en cada momento.

Algunas de las tecnologías que pueden aparecer en este repositorio:

Java

Python

JavaScript

HTML

Bases de datos

Git

Inteligencia Artificial

Y cualquier otra tecnología que resulte interesante 🚀

📚 ¿Por qué hago esto? 📚

Porque creo que la mejor manera de aprender programación es programando.

Cada proyecto es una oportunidad para aprender algo que antes no sabía, cometer errores, encontrar soluciones y mejorar el proyecto siguiente.

Este repositorio es, en cierta forma, un registro de ese proceso.

No busco demostrar que sé hacerlo todo, busco aprender de la mejor manera posible, y siempre de forma divertida.

Dentro de cada proyecto intentaré explicar:

Qué he construido.

Qué tecnologías he utilizado.

Qué he aprendido.

Qué problemas he encontrado.

Qué podría mejorar en el futuro.

🌱 Aprender → Construir → Mejorar

La filosofía del repositorio es sencilla:

Aprender algo nuevo → construir algo con ello → aprender de los errores → repetir.

No importa si un proyecto es pequeño o grande.

Lo importante es que, al terminar cada semana, sepa algo que no sabía al comenzar.

⭐ Este repositorio es mi forma de mantenerme aprendiendo, experimentando y mejorando como desarrollador, un proyecto a la vez.
